# EGMT: Entity-Guided Multi-Task Learning for Infrared and Visible Image Fusion

[![arXiv](https://img.shields.io/badge/arXiv-2601.01870-b31b1b.svg)](https://arxiv.org/abs/2601.01870)
[![Python](https://img.shields.io/badge/python-3.9+-blue)](https://www.python.org/downloads/)

&gt; **IEEE Transactions on Multimedia 2026 (accepted Oct 2025)**  
&gt; Wenyu Shao, Hongbo Liu, Yunchuan Ma, Ruili Wang


## 🔑 Highlights
- **Entity-level semantics** instead of noisy sentence-level text → less hallucination, richer guidance  
- **Multi-task learning**: joint optimization of image fusion + multi-label classification (entities as pseudo-labels)  
- **Entity-guided cross-modal interaction module (ECIM)** for fine-grained visual-text alignment  
- **New benchmark**: entity-annotated splits of TNO / RoadScene / M3FD / MSRS released  
- **SOTA results** on 4 datasets + superior downstream detection performance
